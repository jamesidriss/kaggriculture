# MOON AUTOPSY

Generated by `research/moon_provenance.py` and `policy/rank1/moon_ablation2.py`.
Every number here is measured; nothing is inferred from code inspection alone.

## The problem

C001 loses ~94.6% of its games to two artifacts in the Kaggle dataset
`kksky9k/kaggriculture-r88-rivals`. Over 120 seeds, paired, both seats:

| matchup | record | N | BT score |
|---|---|---|---|
| C001 vs `moon_parent` | 27-473-0 | 500 | **0.054** |
| C001 vs `moon_q13_mg` | 27-473-0 | 500 | **0.054** |

An agent losing 94.6% to a distinct strategy cannot credibly be a rank-1 agent.
This, not another point against the Farm, is the highest-priority problem.

## Finding 1 — Moon is NOT an independent lineage

The catalog labelled Moon an independent lineage. **That is wrong.**

Moon's own header states it is derived from *Kaggriculture submission v9/3, public
V39*, with attribution to thomastschinkel, yhay81, destbreso, aurax7, tetsutani,
prvsiyan and Dmitrii Gluzdov. Identifier Jaccard against C001:

| artifact | Jaccard vs C001 | header claims v9/3 base |
|---|---|---|
| `moon_parent` | **0.7192** | yes |
| `moon_q13_mg` | **0.7110** | yes |
| `farm_2945` | 0.6098 | yes |
| `v51` | 1.0000 | no |

Moon sits *between* the Farm and C001 on identifier overlap and descends from the
same v9/3 root. So 0.054 is not a cross-lineage catastrophe; it is a **family
argument**, and it is one this project can close.

## Finding 3 — Moon's licence is UNKNOWN, not Apache-2.0

An Apache-2.0 licence body appears inside the file. **A licence body is not a
grant.** Four blockers, each independently sufficient:

1. **The derivation chain is broken.** The header says *"Derived from
   `queue_compact.py`"*, and that file **is not distributed**. Apache-2.6
   derivative works must be traceable to a root Work; an incomplete chain cannot
   be verified.
2. **The artifact disclaims submission status in its own header:** *"This
   candidate is unproven and is not an official Kaggle score claim."*
3. **It is marked "FOR LOCAL DISCOVERY ONLY"** — a statement about intended use.
4. **The distributing dataset declares no LICENSE or NOTICE file of its own.**

Verdict: **UNKNOWN**. Permitted use is **analytical opponent and adversarial
benchmark only**. Moon is not a submission candidate and none of its source is
transcribed into any artifact this project submits.

## Finding 4 — the mechanism is a single turn-0 wheat flash-trade

Ablation by intervention, applied at the **def site** so Moon's 43-deep wrapper
chain actually binds the replacement. Every variant must pass the playability
probe before its score is used. 30 seeds, both seats, vs C001:

| ablation | BT score | drop vs control | verdict |
|---|---|---|---|
| control (unmodified Moon) | 0.8667 | — | — |
| **opening → pass-through** | **0.0000** | **+0.8667** | **MATERIAL** |
| RACE update off | 0.8667 | 0.0000 | no effect |
| COURIER off | 0.8000 | 0.0667 | partial |
| CARROT off | 0.8667 | 0.0000 | no effect |
| HERD off | 0.8667 | 0.0000 | no effect |

Median paired margin: control **+$1,259**, opening disabled **−$14,659**. Every
loss under the disabled variant is a loss (min −$32,535, max −$6,145), so the
opening is not a marginal edge; removing it inverts every game.

The layer is four lines:

```python
V9_OPENING_STEP0 = (("BUY_PRODUCT", "WHEAT", 20), ("SELL", "WHEAT", 15))
```

At **turn 0 only**, Moon prepends a wheat buy and a wheat sell to its own market
orders. A flash round-trip on the shared market: buy 20 wheat and sell 15 in the
same turn, before anyone else can act on the price.

### Two measurement traps, both caught

**Trap 1 — an ablation that broke the program and reported as a mechanism.** The
first ablation appended `def _v9_opening(...): return None` to the end of the
file. Moon is a 43-deep chain of `_X_PARENT = agent` bindings, so an appended
redefinition is never called by the chain — and the stub's `None` return made the
wrapper emit nothing. The probe recorded
`REJECT ... never touched the market` and the tournament scored **0-80**, which
the first script printed as:

```
disable_v9_opening       BT 0.0000  drop +0.9000  -> MECHANISM
```

Instrumenting the function at its definition site and running one episode gave
the truth: **`ABL_OPENING_CALLS 0`**. The layer was dead code and the "mechanism"
was a broken program. Fixed in `policy/rank1/moon_ablation2.py`, which
intervenes at the binding site and refuses to use any variant that fails the
playability probe.

**Trap 2 — RACE, RACEPX, CARROT and HERD are all inert here.** Every one scored
exactly the control. Identifier Jaccard cannot distinguish a live layer from a
retained dead one, and neither can code size. Only the intervention can.

## What this means for the champion

Moon is a descendant of the same v9/3 root as our Farm hedge, and its entire
margin over C001 comes from **one turn-0 action**. That is a mechanism this
project can implement independently in its own Apache-2.0 artifact, with no
Moon source transcribed, and then measure.

The hard part is not the mechanism — it is that a turn-0 order is a
**commitment before any observation**, so the transplant must be evaluated on
the real ladder seeds, not assumed. See `reports/RANK1_CHECKPOINT.md` for the
running state.
