## 5. What is the largest limitation remaining?

**The league cannot validate the champion.** Nine of eleven league agents
descend from one author, the top two are the same lineage, and the only
genuinely distinct strong-ish agent is 0-232 against both. Everything the
league measures is therefore internally consistent and externally
unvalidated: a shared family of agents will agree with each other far more
readily than with the field that actually beat us on the ladder.

Second, and close behind: 88,281 public replay episodes stop at **2026-09-25**,
five days before the deadline, so the most decisive ladder worlds are missing.

| "Kaggle requires two arguments, so 1-arg agents were never played" | **our** diagnostics invoked agents directly; Kaggle truncates to `co_argcount` | `R1` |

| "every artifact digest matches the registry" | `core.autocrlf` made disk differ from the recorded LF digest | `R7` |

**None of the competitive results were wrong because of these.** That was
verified, not assumed: `benchmark/isolate_signature_bug.py` shows the pre-fix
`meta.py` (raw callable into `env.run`) and the current adapter produce
identical cash on four matchups.

## 8. Which false conclusions were caused by economic reasoning?

| false conclusion | why it failed |
|---|---|

The pattern: in every case a *mechanism* was identified and then assumed to be
a *cause* without running the intervention.

**No claim of victory is made, and none is supportable.**

Supportable: the pair finishes at **$158k–$183k** median on real ladder-derived
worlds, which is the band observed for 2,900+ rated agents in the public replay
index, and it beats every other public agent we can legally obtain and
reproduce.

Not established: that it is first. Our own submissions finished at 138.5–348.1
against a leader at 3,052.1 — roughly 2,700 points of headroom we did not
close. The top 20 teams have almost no extractable artifacts, so the field we
were measured against is a single author's family plus one weak outsider. A
stronger opponent that we never obtained could easily beat both.

The honest statement: **competitive with reproduced 2,800–3,000-level public
agents, above every other agent legally reproducible, and unvalidated against
the actual leading field.**

## 12. Reusable workflow for the next competition

The durable output of this project is the method, in
`benchmark/` and `simcomp/`:

```
CURRENT OFFICIAL ENVIRONMENT      probe the runtime; never read the schema
  -> LEGAL PUBLIC AGENT CATALOG  digest-addressed, licence-gated, no hand-typed hashes
  -> CANONICAL AGENT LOADER      one loader, arity-agnostic, provenance preserved
  -> PLAYABILITY PROBE           both seats, 719 calls, DONE, non-trivial trace,
                                 market activity. NOT "cash > 3000"
  -> DIGEST UNIQUENESS           self-play refused by content, not by filename
  -> REAL LADDER WORLDS          audited index, stock config, era-checked
  -> DEV / HOLDOUT / SEALED FINAL committed before evaluation, final run once
  -> PAIRED BOTH-SEAT TESTING    every world from both seats
  -> CORRECT STATISTICS          Wilson cross-validated against a second
                                 implementation; exact tests in log space;
                                 BT refused when not identifiable
  -> CHAMPION / CHALLENGER       one hypothesis per challenger, promoted on
                                 paired evidence against BOTH top agents
  -> EXACT ARTIFACT VALIDATION   exact bytes, 720 turns, both seats, silent,
                                 digest == Git blob
  -> SUBMIT EARLY                before the quota is gone
```

Three rules would have changed this run:

1. **A sweep means the league is broken**, not that you are winning.
2. **Never patch the product to fix a symptom you have not localised.** Prove
   which layer is wrong first.
3. **A model that will not converge has told you the model does not apply.** Do
   not print the last iterate.
